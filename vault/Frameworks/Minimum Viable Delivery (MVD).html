Minimum Viable Delivery (MVD)

The smallest complete delivery that lets you see the result.

Minimum Viable Delivery means building the smallest complete thing that can produce the result we want.

The important word is delivery. We are not trying to make the smallest possible product. We are trying to make the smallest thing that is useful enough for someone to actually use and get the result.

A simple way to test an MVD is to finish this sentence:

"After using this, the user can now see ______."

The answer should be something real. Maybe they can see a hidden relationship, find duplicated work, understand a bottleneck, discover a missing document, or make a better decision. If we cannot explain what the user can now see, understand, or do, the feature probably does not belong in the MVD.

FEATURE→WHAT DOES IT GIVE THE USER?→A CLEAR RESULT?→YES: KEEP·NO: DEFER / REMOVE

This is where MVD is different from simply making a small prototype.

A prototype can be small because it is unfinished. An MVD is small because we deliberately removed everything that is not necessary for the outcome.

PROTOTYPE = small because it is not finishedMVD = small because only the necessary parts remain

An MVD should also feel complete enough to use. The essential functions should work, the design should feel consistent, and the system should not make the user wait unnecessarily.

ESSENTIAL+COHESIVE+SIMPLE+FAST=VIABLE DELIVERY

For knowledge systems, this becomes even more important.

The goal is not to store more information or create better folders. The goal is to help people see something inside the information that was difficult to see before.

LOTS OF INFORMATION→STRUCTURE→VISIBLE RELATIONSHIPS→UNDERSTANDING→BETTER DECISION

So do not build a feature just because it is technically possible, looks nice, or is expected in a conventional product.

Build it because it helps produce the intended result.

MVD is not about doing less work. It is about making sure the work we do actually delivers something.

Minimum Viable Delivery: the smallest complete delivery that lets you see the result.
