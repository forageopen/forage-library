Resource Arbitrage (REAB)

Use what already exists instead of spending time building the same thing again.

Having ready-to-use templates, tools, references, and visual assets can make the work much faster. Resource arbitrage means using what already exists instead of spending time making the same thing again.

For example, if we already have a template, we do not need to design the same structure from zero. If there is an existing library, dataset, component, or open-source tool that can do the job, we use it first.

The idea is simple:

WHAT DO WE NEED?→DOES IT ALREADY EXIST?→YES: USE / ADAPT / COMBINE·NO: BUILD

This is especially useful for small repetitive tasks. A button style, document structure, presentation layout, code component, research dataset, or visual asset may only take a few minutes to make, but doing it hundreds of times becomes a waste.

Resource arbitrage reduces this waste by keeping useful things ready and applying them consistently.

MAKE ONCE→USE MANY TIMES→SAVE TIME→FOCUS ON THE REAL PROBLEM

The purpose is not to avoid making new things.

It is to save our effort for the things that actually need to be new.
