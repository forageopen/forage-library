# Welcome Note

A forkable, HTML-first knowledge repository — a "public Obsidian." Every piece here lives as a raw file in this vault: markdown, Word docs, PowerPoint decks, plain text — browsed and rendered client-side, restyled into one consistent look.

## How to use this

- Click any file in the sidebar to read it.
- Drop your own file onto the empty viewer, or click "or click to start a new note," to read or write privately in your browser — nothing you drop or type here touches this repo unless you export it and commit the result yourself.
- Open the **Sidenote** panel (kebab menu) to jot private reading notes on whatever you're currently looking at — stored only in your own browser, never shared.
- Export anything as HTML, PDF, Markdown, Word (`.docx`), or JSON from the kebab menu.
- Drag the thin dividers to resize the navigation, viewer, and sidenote panels. Pick a theme from the palette icon in the ribbon.

## Adding more

Drop a `.md`, `.docx`, `.pptx`, or `.txt` file anywhere under `vault/`, commit, push. It shows up here automatically — no template, no link to add by hand.

Fork it, drop your own files into this vault, push.
