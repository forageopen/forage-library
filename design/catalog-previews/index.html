Research catalog — 3 UI directions

Stage 1 mockups for the Skills / Agents / Commands dashboard under Research. Same fixture data + the real Forage theme tokens in all three. Pick one (or a blend) and it becomes the integrated catalog-view.js. Use the theme switcher at the top of each to check Cherry + a light theme.

A · Dense grid (GitHub-flavoured)

Compact bordered cards in a tight grid. Click a card and it expands inline to a full-width panel with a GitHub-style Code / Preview file header, copy, show-full/collapse, a bundle file list, and download. Fastest to scan when there are many entries.

B · Marketplace gallery

Big cards with a coloured category banner and a large Lucide glyph, generous spacing, strong hover lift. Clicking opens a detail drawer that slides in from the right (the aitmpl.com component-page feel). Most "product marketplace".

C · Native index

No cards. A typographic index of rows with a left rail of tag filters, opening into a full-pane reader with the Code / Preview toggle pinned to the top. Quietest, closest to the existing Forage document viewer.

All three: 2-line/3-line clamped descriptions, tag filter + search, Code vs rendered Preview, Copy, Show-full/Collapse for long docs, per-bundle file list, and a disabled "GitHub · coming soon" button (flips live in Stage 2 when each entry gets its own repo). Download is stubbed with an alert in the mockups — the real build zips the bundle client-side with JSZip.
